# 01 — 正規表現の基礎

字句解析器の役割は、ソースコードという文字の並びを**意味のあるかたまり**（トークン）に切り分けることだ。

```
"int main() { return 42; }"
              ↓
[int] [main] [(] [)] [{] [return] [42] [;] [}]
```

このとき **「どのパターンの文字列を、どのトークンとして認識するか」** を機械に教える必要がある。「`return` という文字列が来たらキーワード扱い」「数字が並んでいたら整数リテラル」「アルファベットで始まる文字列は識別子」── こういう規則を表現する道具が**正規表現**だ。

flex は正規表現で字句解析の規則を書く。第1章で使う最小限を順に見ていく。


## 1. 文字列そのもの

一番簡単なパターンは、文字列そのもの。

```
int
```

これは「`int` という3文字の並び」にマッチする。

ダブルクォートで囲むと、特殊な意味を持つ文字も「そのままの文字」として扱える。

```
"return"
```

これも「`return` という6文字の並び」にマッチする。英数字だけならクォートはあってもなくても同じだが、`;` や `(` のような記号はクォートで囲むのが安全。

```
";"     ← セミコロン1文字
"("     ← 左カッコ1文字
```

flex では、記号は混乱を避けるためにダブルクォートで囲む習慣にする。


## 2. 文字クラス `[...]`

「**この文字のどれか1つ**」を表すのが**文字クラス**だ。

```
[0-9]      ← 0 から 9 のどれか1文字
[a-z]      ← a から z のどれか1文字
[a-zA-Z]   ← アルファベット1文字（大小どちらでも）
[abc]      ← a、b、c のどれか1文字
```

`-` で範囲を指定する。`[0-9]` は「0 か 1 か 2 か ... か 9」のどれか1文字。

範囲は組み合わせられる。

```
[a-zA-Z_]  ← アルファベットまたはアンダースコア1文字
```


## 3. 繰り返し `+` と `*`

「同じパターンの繰り返し」を表すのが**量化子**だ。

```
[0-9]+     ← 数字1文字以上の連続
[0-9]*     ← 数字0文字以上の連続（つまり「0文字でもよい」）
```

`+` は「1回以上」、`*` は「0回以上」。

| パターン | マッチする例 |
|---------|------------|
| `[0-9]+` | `0`, `1`, `42`, `12345` |
| `[a-z]+` | `a`, `hello`, `xyz` |
| `[0-9]*` | （空文字列）, `0`, `42` |

`[0-9]+` は「整数リテラル」を表すパターンとしてそのまま使える。


## 4. パターンの連結

パターンは横に並べると「順番に出現する」という意味になる。

```
[a-zA-Z_][a-zA-Z0-9_]*
```

これは:

- 最初の1文字: アルファベットまたはアンダースコア
- それ以降: アルファベット、数字、アンダースコアの 0 文字以上

つまり **識別子**（C の変数名や関数名）のパターン。`x`、`main`、`my_var`、`buf123` などにマッチする。`1var` のように数字で始まるものはマッチしない。


## 5. 任意の1文字 `.`

ピリオド `.` は「**改行以外の任意の1文字**」を表す。

```
.          ← 改行以外の何でも1文字
```

`*` と組み合わせれば「改行までの全部」になる。

```
"//".*     ← // で始まり、改行までの全部
```

これは C++ スタイルの行コメントのパターンだ。


## 6. 空白と改行

```
[ \t\n]+
```

「空白、タブ、改行のどれかが1文字以上連続している」という意味。

- ` ` は普通の空白（スペース）
- `\t` はタブ
- `\n` は改行

`\` でエスケープされたものは「特別な意味を持つ1文字」として扱われる。flex では空白を読み飛ばすためにこのパターンを使う。


## 7. ch01 で使う正規表現の一覧

| 記法 | 意味 |
|------|------|
| `"int"` | 文字列 `int` そのもの |
| `[0-9]` | 数字1文字 |
| `[a-zA-Z_]` | アルファベットまたはアンダースコア1文字 |
| `+` | 直前のパターンの 1 回以上の繰り返し |
| `*` | 直前のパターンの 0 回以上の繰り返し |
| `.` | 改行以外の任意の1文字 |
| `\t` | タブ文字 |
| `\n` | 改行文字 |

正規表現には他にも `?`、`|`、`{n,m}`、グループ化 `(...)` などがあるが、第1章では使わない。後の章で必要になったときに紹介する。
